# Reels visual style library

Choose **one primary style** for a video; these are **director references**, not 12 prebuilt engines. The code-rendered demo implements an original editorial approach. New styles can be added as a Markdown art-direction file plus a row in `registry.json`.

| Style | Best for |
|---|---|
| [Warm Editorial Product](warm-editorial.md) | Founder-facing breakdowns, AI workflow explanations, product launches |
| [Kinetic Whiteboard Notes](kinetic-whiteboard.md) | Faceless tutorials, captions-first education, product explanation |
| [Premium Paper-Cut Storybook](premium-paper-cut.md) | Narrative shorts, culture, character storytelling, evocative explainers |
| [Pixel Quest Story](pixel-quest.md) | Product tutorials, progress stories, levels/stages, skill lists |
| [Blueprint Logic](blueprint-logic.md) | Engineering concepts, product architecture, AI diagrams, step-by-step mechanics |
| [Source Proof Montage](proof-montage.md) | News evidence, research reels, verified product analysis, audit videos |
| [Graphic Novel Halftone](graphic-novel.md) | Character explainers, stories, comparisons, playful business reels |
| [Clean Product UI](clean-product-ui.md) | Software tutorials, startup apps, AI agents, feature demos |
| [Type-Driven Studio](type-driven.md) | Lyric typography, trend lists, strong intro hooks, manifesto shorts |
| [Soft Clay Infographics](soft-clay.md) | Friendly educational shorts, wellness explanations, product metaphors |
| [Cinematic Luxe Title](cinematic-luxe.md) | Premium product unveil, branding, cinematic teasers |
| [Illustrated Journey Map](map-journey.md) | Travel reels, launch distribution maps, historical journeys |
